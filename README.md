# ChatGPT arXiv Translation Agent

This is an orphan branch containing only the instructions for a ChatGPT App
translation agent.  It has no parent commit and intentionally contains no
legacy Python implementation or API configuration.

Open this folder in ChatGPT App/Codex and give the agent an arXiv URL or ID.
`AGENTS.md` is the authoritative workflow.  Generated papers are written to
`arxiv_outputs/` and are never committed.
